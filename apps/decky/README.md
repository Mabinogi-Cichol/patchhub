# Decky Alpha

已实现游戏模式列表、补丁详情、来源跳转、ZIP 导入、计划确认、事务卸载与恢复。固定 Rust CLI 通过 Python JSON-lines 桥接；宿主配置可信目录和状态目录，前端不能执行 shell。

构建：仓库根目录运行 `npm ci`、`npm run build:decky`；构建 Linux 核心后运行 `npm run package:plugin -w apps/decky`。输出 `plugin-output`，安装后将 `bin/steam-patch` 设为可执行，并以游戏所属用户运行。完整指南见 `docs/client-guide.md`。

真实 Steam Deck 核心扫描及隔离事务已通过；插件 UI 的实机加载 / 控制器验收正在进行。不要把合成测试记作真实成人补丁或游戏内内容验证。

《夜勤病栋》build 16533492 已在 Deck 内置 SSD 完成真实 ZIP 安装 / 指纹检测 / 卸载恢复；用户确认桌面模式及 GE-Proton8-8 游戏模式运行、补丁生效。目录 revision 4 已配置官方下载地址。点击“自动下载并准备安装”，会复用匹配的本地 ZIP 或下载文件，自动校验并显示计划；关闭游戏及更新后确认安装，无需手填路径。

“管理订阅的补丁源”可启用 / 停用网站或添加网站解析规则。扫描实时查询启用的源，使用网站专用适配器或声明式表格规则解析；新游戏无需插件更新。patch.moe 适配器读取官网语言表单和补丁行，按完整标题 / 明确别名匹配，歧义不自动选择。查询失败仅使用此前成功查询的缓存，并标明状态。ZIP 安装保持包内路径、默认目标为游戏根目录，备份覆盖文件并记录卸载事务；不会执行包内 EXE。插件以 deck 用户运行。配置与开发接口见 [源适配器文档](../../docs/source-adapters.md)。
