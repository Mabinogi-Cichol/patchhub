# Decky UX 问题与修复计划

- 更新日期：2026-10-04
- 状态：待施工
- 设计依据：[`design.md`](./design.md)
- 进度记录：[`progress.md`](./progress.md)

## 1. 背景与目标

对照 `design.md` 第 3 节（二级全屏框架）、第 4 节（概览）、第 5 节（补丁管理）、第 7 节（订阅源）及第 9 节验收项 3–8，对当前已部署到 Steam Deck 的版本逐项核对，汇总差异并给出修复方案与验收标准。

实机取证方式：通过 Steam CEF 调试端口读取大屏幕窗口的 React 纤维树与可见文本、截图，并阅读 `@decky/ui` 导出的原生组件源码（`SidebarNavigation` → `PagedSettings`）。

## 2. 问题清单

### P0-1 侧栏顶部缺少不可交互标签（工具名 + 游戏名）

- 设计（第 3 节）：左栏最顶部显示工具名“Steam 补丁管理”，其下显示当前游戏名，两者不可交互。
- 现状：左栏只有“概览 / 补丁管理 / 操作记录 / 管理订阅源”四个可交互项，顶部没有工具名或游戏名标签。
- 证据：实机可见文本依次为 `概览`、`补丁管理`、`操作记录`、`管理订阅源`，没有 `Steam 补丁管理`，也没有作为侧栏标签的 `夜勤病栋`；原生内层组件源码为 `const { page, eInitialFocus, showTitle = !1 } = e; ... showTitle: n`，`showTitle` 默认 `false`，因此传入的 `title` 未渲染。
- 目标：左栏顶部固定两行不可聚焦文本；游戏名单行省略，长名不改变行高。

### P0-2 “管理订阅源”上方缺少分组分割线

- 设计（第 3 节）：侧栏在“操作记录”与“管理订阅源”之间有一条分隔线。
- 现状：`pages` 中已插入 `"separator"`，实机看不到分隔线。
- 证据：截图与可见文本中该位置没有明显分隔；原生内层组件使用 `PageListSeparatorComponent={be}`，需核实 separator 的触发条件与样式。
- 目标：显示与 Steam 原生一致的分组线，且不改变焦点顺序。

### P0-3 右侧面板排版混乱

- 现状与证据：
  - 内容重复渲染游戏名：每个栏目内容都以 `<h1>{game}</h1>` 开头，另有栏目 `h2`，与侧栏标签及原生标题重复（实机文本中 `夜勤病栋` 与栏目名各出现多次）。
  - 信息未按设计左右对齐：概览“补丁状态 / 匹配来源”、补丁详情“当前状态 / 兼容性 / 安装方式”当前是多行 `Status` 文本，而非左标签右值的原生行。
  - 分组与间距不统一：各页 `PanelSection` 标题、段落、按钮间距不一致。
  - 顶部内边距为临时值：`.patch-page { padding-top: 56px }` 用于规避状态栏遮挡，未与原生标题区域统一。
- 目标：游戏名在右侧只展示一次（由侧栏标签或原生标题承担）；内容只保留栏目名与信息；键值信息左标签右值；四页分组、间距、按钮布局统一。

### P1-1 概览操作按钮布局与设计不符

- 设计（第 4 节）：“查看补丁”和“打开来源网页”在同一行左右分布。
- 现状：使用 `ButtonItem` 整行按钮，上下堆叠。

### P1-2 全局订阅源页缺少顶部标签与一致分组

- 现状：`/steam-patch-manager/sources` 直接进入，左栏仅“管理订阅源”，同样缺少工具名标签；“添加源”区域与列表分组需与游戏页统一。

### P1-3 名称与状态文案统一

- 现状：一级 QAM 标题“Steam 补丁管理”、二级标题、栏目命名需与设计一致；匹配源 / 缓存 / 未知来源文案需统一（缓存时间格式、未知来源提示）。

### P2-1 长名称与滚动位置回归

- 侧栏游戏名标签、QAM 游戏行、右侧标题的长名溢出策略需一致；切换栏目后各页滚动位置需保留。

## 3. 修复方案

### 3.1 侧栏顶部标签（P0-1）

1. 先实机核实原生 `PagedSettings` 的 `title` + `showTitle` 渲染位置：
   - 若渲染在左栏顶部：传 `showTitle`，`title` 使用组合节点（工具名 + 游戏名两行）。
   - 若渲染在右侧内容顶部：左栏改为在 `pages` 前叠加自定义标签容器，或使用原生 `PageListColumn` 自建受控侧栏。
2. 标签不可聚焦：使用非 `Focusable` 元素，确保不进入手柄焦点序列，也不被读屏当作可操作项。
3. 游戏名单行省略，溢出与滚动策略与设计第 2 节一致。

### 3.2 分割线（P0-2）

1. 核实 `PageListSeparatorComponent` 的渲染条件，确认 `"separator"` 是否被 `navPages` 正确传递。
2. 若原生不渲染，改用原生分隔样式或显式分隔项，并确认暗色主题下的可见性。

### 3.3 右侧排版重构（P0-3、P1-1、P1-2）

1. 移除四页内容中的 `<h1>{game}</h1>`，游戏名只由侧栏标签 / 原生标题展示一次。
2. 栏目页统一结构：栏目名标题 + 信息分组；信息行改用 Steam 原生左右键值布局（label 左、value 右）。
3. 概览、补丁管理、操作记录、订阅源统一 `PanelSection` 间距与分组；操作按钮按设计排版（概览左右两按钮）。
4. 移除 `.patch-page` 的 56px 临时顶部内边距，改为与原生标题区域一致的留白（随 3.1 结论确定）。

### 3.4 回归（P2-1）

1. 长名称单行省略 / 滚动在 QAM、侧栏标签、右侧标题三处一致。
2. 栏目切换保留各自滚动位置与焦点。

## 4. 实施步骤

1. 用实机探针脚本核实 `showTitle` / `title` 与 separator 的原生渲染（复用 CEF 调试端口）。
2. 实现侧栏顶部标签与分割线。
3. 重构右侧四页排版，抽出共用键值行组件。
4. 本地执行 `npm run typecheck -w apps/decky`、`npm run test -w apps/decky`、`npm run build -w apps/decky`。
5. 备份并部署到 Steam Deck，重载后截图与手柄焦点验收。
6. 在 `progress.md` 追加施工与验收记录。

## 5. 验收标准

对应 `design.md` 第 3、4、5、7 节与验收项 3–8：

1. 左栏最顶部显示工具名与当前游戏名两个不可聚焦标签，游戏名单行省略。
2. “管理订阅源”上方可见原生分组分割线。
3. 右侧不再重复渲染游戏名；栏目名与信息层级清晰。
4. 概览、补丁管理、操作记录、订阅源四页键值信息左右对齐、间距统一。
5. 概览“查看补丁 / 打开来源网页”按设计排版。
6. 手柄焦点依次遍历标签（跳过）、栏目、内容；B 返回行为不变。
7. 切换栏目保留滚动位置；重载插件不触发重复扫描。
8. 全局订阅源页与游戏页视觉一致。

## 6. 风险与待核实

- 原生 `PagedSettings` 的 `title` / `showTitle` 渲染位置需实机确认，决定左栏标签的实现方式。
- 原生 separator 的可见样式需实机确认。
- 顶部状态栏安全区域与原生标题区域的留白需重新核对，避免再次遮挡。
