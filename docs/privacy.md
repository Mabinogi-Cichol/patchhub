# 隐私与本地数据

当前 Alpha 不包含遥测、账号系统或游戏库上传。扫描、匹配与文件指纹计算在本机完成；安装计划、文件备份和事务记录保存在宿主指定的本地状态目录。

Decky 默认启用 patch.moe、Kagura 国内和海外发行商源，以及 HGamer 补丁索引。扫描先读取本地缓存；打开游戏详情后，插件按需读取发行商公开页面，并在匹配不足时向 HGamer 发送该游戏的名称或有出处的名称变体。请求会向对应网站提供正常的 IP 地址和 User-Agent，不发送 Steam 账号、安装路径、build、操作记录或完整游戏库，也不保存网站账号 Cookie。可在订阅源设置中全局关闭任一来源，或仅取消某个游戏的订阅；关闭后不再查询或用该来源补全身份。必要的补丁元数据与成功查询缓存在本机，失败时保留上次结果。本功能仅发现来源，不镜像站点正文或补丁文件。详细边界见 [Kagura 与 HGamer 功能设计](features/kagura-hgamer-fallback/design.md)。

打开官方来源会由浏览器访问第三方网站；获取补丁时会连接目录明确批准的 HTTPS 主机。第三方网站可能要求年龄确认、使用 Cookie 或记录访问，请自行查看其政策。工具不保存网站密码，也不绕过网站验证。

事务记录包含游戏安装路径、AppID、补丁版本和文件哈希。备份可能包含被替换的游戏文件；补丁安装成功后默认会删除本次下载的 ZIP 缓存与事务暂存副本（`.stage`），并默认**不保留**原文件备份（`.backup`，可在“下载缓存”页开启“保留原文件备份”），因此默认无法卸载、只能重新安装；开启后保留备份以支持卸载。存在未完成或冲突事务时，请保留状态目录用于恢复。分享诊断时应移除用户名、绝对路径、下载 URL 中的访问凭据和游戏库清单。

Steam Deck 的 Decky 宿主可能以 root 运行；后端将核心子进程降至配置的 Deck 用户，并设置该用户的 HOME 与 XDG 路径。权限不足会报错，不要求整个 Windows 客户端以管理员身份常驻。

仓库中的签名公钥只用于校验当前开发目录。Alpha 的本地开发签名不代表发行商背书，也不能替代补丁分发许可；本项目不镜像游戏补丁资产。
