# v0.3.0

v0.3.0 将 Windows 客户端迁移至 Flutter，并重新设计游戏库与补丁管理界面。Windows 与 Steam Deck Decky 插件继续使用同一 Rust 核心和 v5 协议。

## 更新内容

- Windows 游戏库采用 Steam 艺术作品横幅、封面导航与信息卡，支持跟随系统、浅色和深色外观。
- 优先读取当前 Steam 账号的自定义艺术作品，其次使用本机游戏库图片；缺图时显示占位，不下载或打包游戏美术。
- 补丁管理增加悬浮操作栏、补丁状态摘要与整行技术详情，统一补丁选择、下载项与镜像的标题排版；支持打开当前游戏目录。
- 保留概览、补丁管理、操作记录、游戏订阅及全局来源；安装状态、人工确认、本地 ZIP 和覆盖安装均按核心实际能力呈现。
- 安装下载阶段显示真实下载速度；统一应用与安装/卸载器品牌图标。
- 修正 Windows 关闭流程：取消可取消的读取任务，并通过正常窗口关闭路径退出。旧 React/Tauri Windows 客户端已退役。

## 下载与安装

| 用途 | 文件 |
| --- | --- |
| Windows 64 位安装版 | `Steam.Hentai.Patch_0.3.0_x64-setup.exe` |
| Windows 64 位便携版 | `steam-patch-manager-windows-portable.zip`，完整解压后运行 `steam_patch_windows.exe` |
| Steam Deck / SteamOS | `steam-patch-manager-decky.zip`，通过 Decky Loader 安装/更新 |
| Steam Deck 终端安装 | `install-decky.py`，用法见 [README](https://github.com/Mabinogi-Cichol/steam-hentai-patch#readme) |

请使用完整安装包更新，保持客户端、核心与 worker 配套。Windows 继续使用既有状态目录；更新前关闭旧程序。`SHA256SUMS.txt`、`checksums-*.json` 提供文件校验，`dependencies-*.cdx.json` 为依赖清单。GitHub 自动提供的 Source code 是源码。

## 验证与已知边界

- Windows 原重写已完成既有验收；Modern 界面曾通过 205 项完整回归。后续布局与标题修订已完成对应回归、静态分析及真实 Windows 深浅色截图矩阵，覆盖默认、宽窗、最小窗口及文字缩放；普通入口本地候选正常退出。
- 真实用户自定义 grid 图片和操作系统 125%/150% DPI 切换尚未实测；自定义资源优先级以隔离夹具验证。文字缩放测试不等同于系统 DPI 切换。
- 某些官方 ZIP 下载受站点 Cloudflare HTTP 403 限制，保留外部遗留；可按界面提供的来源网页及本地 ZIP 路线处理。
- 新 ZIP/EXE 安装沿用直接覆盖语义，不创建自动备份或回滚；写入后失败、取消或中断会保留已写内容，必要时重新安装。请自行备份重要文件和存档，安装前关闭游戏并暂停 Steam 更新。
- Windows 安装包未配置 Authenticode 签名。本次发布不代表已将最终发行包部署到 Steam Deck，亦不扩大此前未执行的真实游戏安装和中断矩阵结论。
