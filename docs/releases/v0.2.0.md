# v0.2.0

## 更新内容

- 来源缓存与游戏匹配重构：来源索引按源更新并共享复用，新增手动更新、运行期间自动更新间隔、覆盖状态与任务进度；新增游戏增量匹配，单游戏可重新匹配。
- 普通来源优先，未确认命中时使用 HGamer 补查；保留失败后的可用缓存，并区分尚未完成与确认无结果。
- 订阅源管理改为可独立折叠的卡片，保留展开选择，收起时仍可查看任务和失败摘要。
- 修复 VenusBlood FRONTIER International 的 Kagura 补丁漏匹配，以及重新匹配时显示 Python Exception；使用已确认 AppID 的精确上游文章关联，不依赖模糊标题猜测。
- 修复下载缓存占用始终显示占位提示，改为读取核心的实际统计，清理后刷新。
- ZIP 与受支持 EXE 使用直接写入流程，减少重复解包、完整暂存与备份占用；修复大包 EXE、ZIP64、来源正文读取取消及缓存遍历问题。
- 新增安装备份占用与清理入口、Decky 终端安装脚本，并更新双端共享协议与界面。

## 下载与安装

| 用途 | 附件 |
| --- | --- |
| Windows 64 位安装版 | `Steam.Patch.Manager_0.2.0_x64-setup.exe` |
| Windows 64 位便携版 | `steam-patch-manager-windows-portable.zip`，完整解压后运行 `steam-patch-windows.exe` |
| Steam Deck / SteamOS | `steam-patch-manager-decky.zip`，通过 Decky Loader 的 ZIP/URL 安装入口安装 |
| Steam Deck 终端安装 | `install-decky.py`，使用方式见 [README](https://github.com/Mabinogi-Cichol/steam-hentai-patch-searcher#readme) |

`SHA256SUMS.txt` 覆盖发行附件；`checksums-*.json` 为两端 ZIP 校验信息，`dependencies-*.cdx.json` 为依赖清单。GitHub 自动提供的 Source code 是源码。

## 使用边界与已知限制

- **新 ZIP/EXE 安装直接覆盖文件，不创建自动备份，也不自动回滚。写入后取消、失败或中断会保留已写入内容，必要时重新安装；请自行备份重要文件和存档。** 历史事务仍按其原有记录处理。
- 安装前关闭游戏、暂停 Steam 更新。来源命中不保证当前游戏版本、本体/DLC 或语言适配；手动候选需自行核对。
- 第三方网站变更、登录/网盘要求或不支持的安装器行为可能影响获取与安装；工具不附带、镜像游戏补丁，也不绕过网站要求。
- Windows 安装包没有 Authenticode 签名，系统可能显示未知发布者。
- 已有双端自动化和部分 Steam Deck 部署/页面/安装记录；VenusBlood 修复通过真实设备的隔离状态及在线元数据对比。Windows 完整实机矩阵、来源任务/休眠调度、实体手柄及新版安装链完整取消/中断回归仍未全部验收。本发行不将这些项目列为已通过。

- npm 生产依赖审计为 0；开发构建依赖仍有 [braces 栈耗尽公告](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm) 导致的 7 条 high 报告，上游暂未提供修复版。本项目相关构建清理使用固定模式，未接入游戏或来源输入；本轮未重跑 RustSec 审计。
