## 新增与优化

- 重构自定义订阅源导入为单文件自描述 Lua，支持一键复制 AI 提示词并直接粘贴源码导入
- 新增导入自定义索引订阅源成功后自动触发强制初次更新
- 统一双端订阅源模型与角色文案为“索引源”和“补查源”，并为全局来源页新增折叠快捷刷新与全部更新按钮
- 新增本地游戏数据缓存统计与清理功能，并将 Decky 全局设置拆分为“全局来源”“缓存管理”和“关于”三个页签
- 新增关联 DLC 匹配归类、本地安装状态检测与双端适用条件展示
- 订阅源更新支持任务内通用浏览器会话，提升复杂站点抓取兼容性
- 为 Windows 客户端右上角设置入口增加订阅更新中状态指示与动效

## 问题修复

- 修复 Steam V2A 分片应用元数据解析问题，改善游戏信息与关联 DLC 读取兼容性
- 修复 Windows 端订阅源更新或匹配期间未同步展示查询状态与进度条的问题
- 修复 Windows 端可安装补丁状态配色不一致的问题
