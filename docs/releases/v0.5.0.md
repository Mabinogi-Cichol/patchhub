## 新增与优化

- 全部内置补丁来源改用 Lua 脚本，支持在 Windows 和 Steam Deck 导入、查看、编辑及删除自定义脚本来源。
- 支持修改来源显示名称，默认来源名称统一为 Shiravune。
- 内置来源脚本随版本更新并支持只读查看，自定义来源统一通过脚本导入，简化来源管理界面。
- 本次来源迁移不复用旧索引与旧候选，升级后请重新更新来源并匹配游戏。

## 问题修复

- 修复 Shiravune 网站访问验证导致来源更新失败的问题，普通更新与定时更新支持后台自动获取列表。
- 修复脚本来源首次更新失败后不再进入自动调度的问题。
- 修复 Steam Deck 脚本编辑器打开后不在可见区域，以及脚本错误信息显示不完整的问题。
