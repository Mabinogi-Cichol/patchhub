# v0.2.1

v0.2.1 修复 VenusBlood FRONTIER International 等 EXE 补丁在分析阶段因安装器显示文本编码而失败的问题。Windows 客户端与 Steam Deck Decky 插件均包含修复，外部协议继续使用 v5。

## 修复与调整

- 安装器向导、消息和变量值等无业务用途的显示文本按长度跳过，不再因无法按 GB18030 或 UTF-16 解码而阻止安装分析；路径、脚本和结构读取仍按原规则检查。
- 删除未被界面或安装流程消费的许可正文/变量映射字段，内部 graph/behavior 报告升为 v3，核心与 worker 配套更新；安装条件、载荷选择和文件写入语义不变。
- 同步独立 Python 参考实现及合成 golden，补齐异常显示字节、长度头、截断、条件及生命周期回归；样本校验工具适配当前生产流式提取协议。
- 修正客户端指南和 Decky README 中过时的“失败自动回滚”“每三秒续租”及协议 v4 描述。

## 下载与安装

| 用途 | 文件 |
| --- | --- |
| Windows 64 位安装版 | `Steam.Patch.Manager_0.2.1_x64-setup.exe` |
| Windows 64 位便携版 | `steam-patch-manager-windows-portable.zip`，完整解压后运行 `steam-patch-windows.exe` |
| Steam Deck / SteamOS | `steam-patch-manager-decky.zip`，通过 Decky Loader 安装/更新 |
| Steam Deck 终端安装 | `install-decky.py`，具体要求与用法见 [README](https://github.com/Mabinogi-Cichol/steam-hentai-patch-searcher#readme) |

请使用本版本完整安装包更新，保持核心与 worker 配套；旧核心不能读取新版内部报告。无需迁移已有收据。`SHA256SUMS.txt`、`checksums-*.json` 提供校验信息，`dependencies-*.cdx.json` 为依赖清单。GitHub 自动提供的 Source code 是源码。

## 验证与已知边界

- 本地 Rust 604 项、Python 40 项、格式和 Clippy 检查通过；版本调整后的锁文件/版本一致性与 SBOM 测试通过。用户已确认问题修复。
- Steam Deck 的生产 bwrap 沙箱中，9 个合成整包及 VBF（3 个成员）、夏日本体（2,502 个成员）、夏日 DLC（5,874 个成员）的完整报告、提取字节、CRC 和 SHA 校验通过；修复源码已完成插件部署和真实 RPC/页面验证。这不等同于本次 CI 发行包的重新部署验收。
- 本地 Windows 实样本沙箱因创建私有暂存目录的 ACL 错误 5 尚未完成；旧三款 2303800/3606360/3721970 缺少本地样本。本次不将这些项目改记通过，完整 Windows 实机矩阵、手柄及取消/中断矩阵仍保留原有验收边界。
- 安装语义沿用 v0.2.0：新 ZIP/EXE 安装直接覆盖，不创建自动备份或回滚；写入后失败、取消或中断保留已写内容，必要时重新安装。请自行备份重要文件和存档，安装前关闭游戏并暂停 Steam 更新。历史事务按其原有记录处理。
- Windows 安装包没有 Authenticode 签名。其他来源、下载及安装限制沿用 [v0.2.0 说明](https://github.com/Mabinogi-Cichol/steam-hentai-patch-searcher/releases/tag/v0.2.0)。
