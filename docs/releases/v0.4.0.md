# v0.4.0

v0.4.0 是项目统一为 PatchHub 之后的第一个正式版本，也是 Windows 与 Steam Deck 客户端首次内置自更新的版本。两端继续使用同一 Rust 核心与 v5 协议。

## 更新内容

- 品牌统一为 PatchHub：程序名、图标、安装/卸载器、更新说明与下载包名称统一；安装版与便携包改用 `patchhub` 前缀。
- Windows 与 Decky 新增客户端自更新：从正式 Release 检测新版本、下载并校验受管理文件，随后重启替换；卸载时按已提交清单清理受管理文件，保留用户额外文件。v0.3.0 及更早版本没有更新器，首次升级请手动安装本版，此后可在应用内更新。
- 修复全局来源页布局：启用开关、自动更新、索引状态与调度详情分组，自动更新间隔输入框与标题排版；隔离来源展开与页面滚动的状态键，消除滚动后展开异常与灰块。
- 主题完善：跟随系统、浅色与深色使用三态图标（系统图标为左右半太阳与半月亮组合），标题栏随所选模式更新；相同实际明暗下切换模式也会刷新；深色主题调整为中性黑灰。
- 补丁、镜像与语言选择统一为锚定式菜单，保留原选择框外观，包含勾选、选中背景与展开/收起动效，遵循系统减少动画设置并支持键盘操作。
- 修复补丁状态切换导致的选择丢失与误报；候选补丁名称移除拼接后缀；统一 Windows 与 Decky 的候选安装流程，移除额外确认。
- 修复跨 Tab 操作栏与详情展开异常；修复 Windows Release 字体资源增量缓存导致主题图标空白的问题。
- 新增分平台开发构建入口：`build-windows.bat` 增量构建并启动本地预览，`build-decky.bat` 通过 WSL 构建 Decky 发行包；新增 `-Preview` 模式。发行包仍由原有完整构建流程生成。
- CI 按改动范围选择需要构建的模块，纯文档推送跳过构建，减少无关等待。

## 下载与安装

| 用途 | 文件 |
| --- | --- |
| Windows 64 位安装版 | `patchhub-windows-x64-setup.exe` |
| Windows 64 位便携版 | `patchhub-windows-portable.zip`，完整解压后运行 `patchhub.exe` |
| Steam Deck / SteamOS | `patchhub-decky.zip`，通过 Decky Loader 本地 ZIP 安装/更新 |
| Steam Deck 终端安装 | `install-decky.py`，也可使用 [README](https://github.com/Mabinogi-Cichol/patchhub#readme) 中的在线安装命令 |

请使用完整安装包更新，保持客户端、核心与 worker 配套。Windows 从 v0.3.0 升级需手动运行本版安装包，更新前关闭旧程序；本版及之后的版本可在应用内检查更新。`SHA256SUMS.txt`、`checksums-*.json` 提供文件校验，`dependencies-*.cdx.json` 为依赖清单。GitHub 自动提供的 Source code 是源码。

## 验证与已知边界

- 合入前已完成来源布局、补丁选择、下拉选择与主题相关的 Flutter 回归、静态分析和深浅主题渲染检查；构建入口的 Windows 快速预览实际构建通过，Decky 流水线以带空格夹具验证控制流，并以 Tag 对应 CI 构建为正式发行证据。
- 本轮未对最终发行包执行 Steam Deck / Windows 实机部署、真实游戏安装与卸载矩阵、实体手柄、系统 125%/150% DPI 或真实自定义艺术作品验收。自动化与渲染检查结果不等同于上述实机项目通过。
- 某些来源的官方 ZIP 下载仍受站点 Cloudflare HTTP 403 限制，属外部遗留；可按界面提供的来源网页与本地 ZIP 路线处理。
- 补丁安装仍为直接覆盖写入，不创建自动备份或回滚；写入后失败、取消或中断会保留已写内容，必要时重新安装。请自行备份重要文件与存档，安装前关闭游戏并暂停 Steam 更新。
- 覆盖安装不会删除上一版本多出的客户端文件；本版起卸载器按已提交文件清单清理受管理文件并保留无关文件。
- Windows 安装包未配置 Authenticode 签名。依赖审计与许可证材料的核对范围与此前记录一致，本版未重新完成全量安全审计。
