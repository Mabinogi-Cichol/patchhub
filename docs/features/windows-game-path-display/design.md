# Windows 游戏路径显示修复

施工状态与验证见 [progress.md](progress.md)。

## 目标与范围

Rust 扫描得到的规范路径在 Windows 上包含 `\\?\` 前缀，客户端直接显示后影响阅读与复制使用。仅在 Flutter 展示层将扩展盘符路径转成普通盘符路径，将 `\\?\UNC\server\share` 转成 `\\server\share`。

覆盖补丁管理的“更多游戏信息”、无补丁结果的游戏信息和多库游戏的库位置文本；文本选择复制使用显示值。模型、缓存、RPC、目录打开及安装文件操作仍使用原路径，不修改后端。

## 实施与验收

复用现有 presentation 模块提供一个纯字符串格式化函数，由三个界面位置调用；普通路径和其他命名空间路径保持原样。不添加配置、重试或路径存在性检查。

验收包括盘符/UNC/普通与 Linux 路径格式化、长路径布局和选择复制、模型原始路径保持不变。定向 Flutter 测试与静态分析通过后记录结果；原生应用验收单独记录。

测试数据须提供 GameInstall 协议要求的安装路径与库路径；无补丁详情的显示回归使用带前缀的 Windows 路径，验证展示值已转换。不能为了兼容缺失必填字段的夹具，在生产代码中增加空值兜底。
