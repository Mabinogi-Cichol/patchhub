## 目标与范围

- 仓库名：`steam-hentai-patch`。英文名：Steam Hentai Patch。中文名：Steam 黄油补丁助手。
- 简介：一站式查找、下载并安装 Steam 黄油的成人内容补丁。
- 更新 Windows、Decky 可见标题、应用元数据、SBOM、README 和当前下载入口；GitHub 仓库改名并同步 origin。
- 保留已有数据目录、Tauri identifier、Decky 安装目录、内部包名、路由、可执行文件和 Release 附件名，避免丢失状态或破坏现有发行附件链接。
- 历史验收证据中的原名称、路径和素材生成提示词不改写。横幅同步替换中英文名称。

## 实施与边界

Decky 原显示名也是 Loader 身份。终端安装器只识别本项目新旧两个名字，读取旧版任务、备份旧包、安装新包以及失败恢复时使用对应身份；Loader 3.2.9 的 browser.py 按元数据名称查找已安装插件，因此跨名称时先通过 Loader 卸载旧身份，再确认安装新包，避免同目录遗留旧运行实例。成功后迁移本插件在 Loader 设置中的名称。兼容由已发布旧包直接驱动，不增加通用迁移框架。
