# Windows 全局来源布局修复

施工状态见 [施工记录](progress.md)。

## 目标与范围

修复全局来源页底部及发行商来源展开后的灰色错误区域，并修正自动更新间隔标题排版。仅修改 Windows Flutter 来源页，不改变来源调度、更新间隔取值或保存接口。

## 原因与方案

- `ListView` 使用 `PageStorageKey('global-sources')` 保存滚动偏移；高级规则展开区缺少独立键，会读写同一存储位置，造成 `bool` 与 `double` 类型冲突。
- 发行商卡片内的详情展开区缺少独立键，会与外层来源卡片共用展开状态。输入框与可选择详情文本也有内部滚动位置，不能继承展开区的状态键。
- 为高级规则、来源详情、规则输入框、间隔输入框和可选择详情文本设置独立 `PageStorageKey`，保留滚动位置与正常折叠行为，不禁用状态存储或捕获并隐藏异常。间隔输入框的键继续包含当前间隔，保留保存后按新值重建输入框的行为。
- 自动更新间隔标题作为输入框上方的普通文本自然换行，留出明确间距，不再使用与边框相交的浮动标题。

## 验收

- 多来源页面滚动至底部，展开高级规则，再返回发行商卡片并展开，均无 Flutter 异常。
- 来源卡片、调度详情、高级规则各自保存展开状态，不互相影响；折叠、滚动、再次展开后状态正确。
- 深浅主题和最小窗口放大文字下，间隔标题不与输入框相交，输入与保存仍可操作。
- 自动化通过与原生 Windows 界面验收分别记录，不以测试代替用户现场验收。

## 2026-10-27 排版与主题图标补充

- 来源启用开关移至卡片标题右侧，折叠时也可操作；保留启用状态文字与开关提示。
- 展开区采用左对齐分组：自动更新间隔输入、保存和关闭说明为一组；索引覆盖状态与手动更新为一组。输入框使用 200 逻辑像素的紧凑宽度，Wrap 随可用宽度换行，不限制业务输入。
- 详情与卡片内容统一左边距，去除 ExpansionTile 展开时额外的上下边框；保留原有独立 PageStorageKey。
- 页面重新匹配按钮左对齐，分组标题与卡片之间增加间距。
- 标题栏主题按钮根据当前 ThemeMode 显示左半太阳与右半月亮组合（跟随系统）、太阳（浅色）、月亮（深色）；菜单同样展示对应图标并保留选中标记。组合图标沿用两种现有图标裁切拼合为 20 像素，不新增图片资源。沿用现有主题切换，不添加持久化或新的主题状态。
- 补充验收：侧栏占用后约 580 像素内容宽度、深浅主题和 1.0/1.5 文字比例下不溢出；切换三种主题后按钮图标正确，游戏库状态和扫描次数保持。

## 主题图标空白修复

- 实际反馈为 Release 标题栏图标空白。控件存在与尺寸测试不足以覆盖，补充加载 MaterialIcons 字体后的像素绘制检查，分别核对组合图标左右两半可见。
- 本地旧 Release 字体缺少 `dark_mode_outlined`（U+EF9F）和 `light_mode_outlined`（U+F162）；普通增量构建后字体仍未更新。当前 Flutter 3.47.7 的 `BundleWindowsAssets.inputs` 未包含图标裁剪实际读取的 `app.dill`，资源缓存标记早于新增图标的代码编译结果。
- 构建入口仅删除 `.dart_tool/flutter_build` 中 `release_bundle_windows-x64_assets.stamp`，促使资源与裁剪字体重新生成；保留其他构建缓存及打包资源，不关闭图标裁剪，不更改 SDK。
- 三种主题直接使用常量 Icon，系统组合图标明确占用 20×20 逻辑像素。验收还需核对生成的 Release 字体包含两种字形，不能只看 widget 测试。

## 相同明暗下切换主题模式

- 主题按钮显示所选模式；系统为深色时，跟随系统与手动深色互换，实际 ThemeData 相同，不能依赖主题变化触发入口刷新。系统为浅色时同理。
- 菜单选择在更新既有应用主题状态的同时，调用当前 LibraryPage 的 setState 重建入口；不复制主题模式、不更换页面键，也不新增全局状态层，保留游戏选择与筛选。
- 回归覆盖系统深浅两种场景，反复从系统切到相同明暗的显式模式再切回，检查入口图标、实际明暗与扫描次数。
