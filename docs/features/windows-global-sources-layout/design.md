# Windows 全局来源布局修复

施工状态见 [施工记录](progress.md)。

## 目标与范围

修复全局来源页底部及发行商来源展开后的灰色错误区域，并修正自动更新间隔标题排版。仅修改 Windows Flutter 来源页，不改变来源调度、更新间隔取值或保存接口。

## 原因与方案

- `ListView` 使用 `PageStorageKey('global-sources')` 保存滚动偏移；高级规则展开区缺少独立键，会读写同一存储位置，造成 `bool` 与 `double` 类型冲突。
- 发行商卡片内的详情展开区缺少独立键，会与外层来源卡片共用展开状态。输入框与可选择详情文本也有内部滚动位置，不能继承展开区的状态键。
- 为高级规则、来源详情、规则输入框、间隔输入框和可选择详情文本设置独立 `PageStorageKey`，保留滚动位置与正常折叠行为，不禁用状态存储或捕获并隐藏异常。间隔输入框的键继续包含当前间隔，保留保存后按新值重建输入框的行为。
- 自动更新间隔标题作为输入框上方的普通文本自然换行，留出明确间距，不再使用与边框相交的浮动标题。

## 验收

- 多来源页面滚动至底部，展开高级规则，再返回发行商卡片并展开，均无 Flutter 异常。
- 来源卡片、调度详情、高级规则各自保存展开状态，不互相影响；折叠、滚动、再次展开后状态正确。
- 深浅主题和最小窗口放大文字下，间隔标题不与输入框相交，输入与保存仍可操作。
- 自动化通过与原生 Windows 界面验收分别记录，不以测试代替用户现场验收。
