# 默认值限制处理清单

日期：2026-10-19。关联：[设计](design.md) · [施工记录](progress.md) · [修复计划](fix-plan.md)。

| 类别 | 已实施处理 | 保留理由或适用边界 |
| --- | --- | --- |
| 文件记录尾字节 | 原始读取与记录，0/1/17/255 回归 | 不决定记录长度或压缩流，不设置值名单 |
| 普通项目/卸载/界面/语言/SessionVar/图片引用/OS 配置 | 按字段类型和长度读取 | 实际 schema 版本、CArchive 类/引用标记仍决定布局 |
| 固定事件列表和顺序 | 读取全部可解析事件，保留生命周期，按实际阶段编译 | 必需动作按当前 Lua 子集处理；未知动作不能冒充已执行 |
| include 构建期选择与类型 | 完整图读取并保留，不因非默认 source_kind 拒绝 | include 引用/版本/字符串边界是格式；扫描 inventory 只是诊断，不授权 |
| runtime_folder、属性、时间戳与 opaque 默认值 | 不作为普通载荷提取准入 | 成员偏移/长度/压缩标记/CRC 与摘要仍约束实际解包 |
| shortcuts/icon/font 与卸载/重启偏好 | 配置保留，插件文件复制不应用这些附带动作 | 普通游戏文件事务沿用插件规则，不运行原始 EXE |
| save/saves/userdata/.sav/.save 名称 | 删除启发式拒绝 | 实际相对目标路径与已有文件覆盖/失败恢复仍由事务处理 |
| file condition 与 packages | 编译条件、Install 状态和多包 OR，按当前/原始可信事实筛选 | Enabled 表示包选择界面的启用状态；install_type/extra 不猜测为运行时 gate |
| 条件子路径 | 完整路径规范化，目录/叶文件名分别处理 | basename 校验仅用于单文件名；条件读不到或不成立按具体事实报告 |
| 报告与提取清单 | v3 报告携带逐成员条件，核心选中后 worker 提取同一子集 | 验证路径/长度/摘要/归属，防止清单与实际转换内容不一致 |
| 重装条件与身份 | 同 EXE/meta/size 的最近可信事务原始事实可用于重算 | 重新计算选择并核对成员身份、现场文件；不将策略版本变化当新包 |

以下检查保留，并非样本默认值许可：PE/压缩流格式及实际支持的解码器、对象类/schema/reference、非显示字符串编码及全部字符串的长度/结构界限、对象计数/完整消费、时间戳布局标记、密码对象尚未实现的布局、压缩字段所指示的实际两种解码操作、载荷 CRC/SHA、资源与时间预算、目标相对路径、来源/实例/事务绑定和恢复一致性。涉及尚未实现的必需内容生成或 Lua 运算，继续按具体操作报错；不宣称任意安装器均可处理。

事件处理验证边界：屏幕数组后的两个进度显示配置 DWORD 目前读出但未映射。While OnPreload 作为静态准备步骤处理，隐藏 While 屏幕且其中含选择副作用时，尚未与官方运行时核对。该边界不转化成默认配置白名单。

包对象中名为 condition 的字符串是历史逆向标签，其确切语义尚未确认，当前保留原值，不据此猜测安装条件或恢复默认值 gate。官方 [GetPackageProperties](https://www.indigorose.com/docs/suf/program_reference_actions_setupdata_getpackageproperties.htm) 定义的选择字段为 Install，Enabled 为包选择界面的启用状态；后置字符串不在其独立安装条件字段列表中。


显示字段仅消费长度头所声明的字节，不参与安装准入，也不产生显示编码错误。完整图不再输出 `variables`/`terms`，behavior 不再输出 `terms`。SessionVar 仍读取名称、消费值与 flag，但不维护显示值映射或拒绝重复名称；名称和脚本的严格解码未扩大跳过范围。详见[跳过显示文本解码计划](skip-display-decoding-plan.md)与[施工记录](progress.md)。
