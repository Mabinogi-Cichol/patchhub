日期：2026-10-14（Asia/Shanghai）。状态：**2026-10-15 已实现，自动化与四款双平台正式隔离 worker 回归通过，候选包已生成；部署与设备运行验收通过，用户确认本轮不执行实际游戏安装与生效验收。**

## 1. 修订目标

用户要求移除降低兼容性的多余防御性策略。此前方案将夏日 DLC 文件记录尾字节从只允许 0 改成审核后允许 0/1，仍属于扩大白名单，现取消该路线。

新目标是让解析器读取格式、让文件安装器处理载荷；停止以“与已有样本默认值相同”决定是否能安装。固定长度字段的内容不同不等于结构损坏，安装器附带的向导、快捷方式、字体注册、卸载器及重启配置不同也不应让普通文件提取失败。不新增 AppID、包摘要、游戏 build 或字段取值许可表。

可定位但未参与文件复制的配置字段读出并记录；不把先完成每个字段的逆向审核设为通用文件安装前提。需要进一步研究字段含义时作为后续资料任务，不继续用默认值匹配阻挡可提取载荷。

## 2. 已确认的问题

实际夏日 DLC 中文 v2.02.1 包为 Setup Factory 9.5.2.0，279,515,928 字节；EXE SHA-256 为 de370e86645e273bae205517b49077a9fd682a9d73309c518f5524d96216ecad。两次实机任务均停在 analyzing_installer。

- 5,874 条 CSetupFileData 记录 CRC 后的尾字节都是 1，当前 graph.rs 用 byte() 强制为 0。第一处偏移为元数据 45133；读取字节是解析步骤，要求值为 0 是额外策略。
- runtime_folder 使用 15 种 Archive\www\... 内部子目录，behavior.rs 强制精确等于 Archive。
- On Preload 的 File.DoesExist 检查 Cosplay DLC 下的相对路径；当前编译器把整个子路径作为 basename，触发 unsafe_basename。

仅在内存诊断副本去掉这三处假设后，Python 参考解析器完整处理 3,112,598 字节元数据、59 个事件、2 个 include，并生成 Game.exe 存在且 Script.vdf CRC32=2002373744 的条件 IR。当前实例的只读关键文件核对满足这一条件。该结果不是正式 Rust 分析、转换或安装验收。

原始证据保留在忽略目录 `.artifacts/summer-memories-diagnosis-20261014/`。前一轮日志和实验结论沿用，本轮没有重新连接设备。

## 3. 计划删除的策略及替代处理

| 位置 / 当前检查 | 计划处理 | 验收要点 |
| --- | --- | --- |
| graph.rs：文件尾字节必须为 0 | 按实际布局读取原始字段并保留，不做取值准入；不用 0/1 白名单替代 | 改变字段值不会改变后续解析位置；可提取包不因这个值被拒绝 |
| graph.rs：项目、卸载、界面、语言等配置与 expected 常量数组匹配 | 逐调用点分离真正的结构标记和普通配置。普通配置按长度/类型读取；不影响插件文件复制的字段不再阻断 | 显示文字、界面选项和附带配置变化不使同一载荷失去安装能力 |
| behavior.rs：runtime_folder 必须精确为 Archive | 解析实际内部资源位置，支持归档子目录，依据成员表提取；不要把所有路径强行改写成 Archive | 夏日的全部子目录及多层目录正确映射，无漏件和重名覆盖 |
| behavior.rs：attributes 只允许 0/32、原始属性必须为 1、强制属性必须为 0 | 读取原始属性，依据目标平台已有文件写入能力处理；Windows 专属属性在 SteamOS 上不成为提取许可条件 | 普通合法属性组合可安装；需要的执行权限正确保存 |
| behavior.rs：时间戳、覆盖、安装顺序及 opaque 字段必须等于样本字节 | 删除样本字节相等作为许可的要求；长度由格式决定，数据进入结构记录，实际写入沿用插件事务规则 | 时间、覆盖偏好及无关选项变化不影响可提取载荷 |
| behavior.rs：shortcuts/icon/font 必须全空 | 插件只安装游戏文件，不执行官方安装器的快捷方式、字体注册等附带操作；配置记录为未应用，不阻断文件复制 | 带非空配置的包仍可提取和安装对应载荷 |
| behavior.rs：按 save/saves/userdata 目录名和 .sav/.save 后缀提前拒绝文件 | 移除名称启发式准入，按实际目标和既有安装/覆盖/恢复事务处理；文件名不单独决定能力 | 同名合法载荷不误拒，既有用户文件处理仍符合事务规则 |
| behavior.rs：condition 为空、install_type=All、extra=None、packages 为空 | 解析并求值实际载荷选择信息；空/default 不再是唯一可接受值，不把所有条件无脑设为真 | 分支选择结果正确，不安装明确未被选择的组件 |
| graph.rs / behavior.rs：事件、include 选择和界面 API 只认固定默认组合 | 结构读取与产品执行分开，按实际作用处理。未由插件执行的向导/展示配置不阻断复制；确实生成或改变必要载荷的步骤由适配器实现 | 不再因界面事件名称/配置变化拒绝；需要生成内容时不误报完成 |
| behavior.rs：条件子路径传给 basename 专用校验 | 用完整相对路径处理只读条件，按目录和叶文件名拆分；basename 校验只用于实际单文件名字段 | Cosplay DLC 等子目录只读条件可编译；条件 IR 使用正确路径 |

生产修改以共享 Rust `crates/installer-format` 为主；`installer-worker`、核心报告和调用点按字段结构变化同步。Python 脚本仅作为研究/对照工具维护，不恢复为生产安装引擎。

盘点范围覆盖整个 SF9.5–9.7 解析与行为链路，不能只改夏日触发的三行。每处保留的检查必须能指出它保障的真实结构、解包操作或文件事务；“没有见过这个值”“不是默认值”“还未人工审核”不能单独成为拒绝理由。不得把删除的策略迁移到报告验证、核心授权或其它命名的白名单中。

## 4. 必要读取与产品行为

- PE/版本布局、类引用、长度/计数、压缩流边界及 CRC 用于读取正确文件；保留它们作为格式完整性检查，不能混入安装偏好默认值。版本标识只选择布局，同布局的版本差异不另设许可名单。
- 实际写入目标、载荷一致性、取消/失败恢复仍由已有文件事务负责；格式层不再重复设置文件名和属性许可表。
- 真实载荷分支需要求值，差分/解密/外部生成等确实影响文件内容的操作需要实现。缺失实现时报告具体缺少的提取操作；不以笼统“未审核”“项目选项不支持”代替定位，也不把跳过必需操作算作安装成功。
- 以资源与平台能力确定解包预算，预算问题单独报告内存/空间/时间原因，不能伪装成格式白名单。
- 不新增用户确认页、人工审核流程、安全开关或逐游戏配置。本轮不改变下载来源选择、UI 流程、Steam DLC 设置或已存在的成功事务。

## 6. 验收标准

1. 文件尾字节、资源目录、属性、时间戳和附带配置的合法变化不因偏离样本默认值被拒绝；不存在换名保留的等值许可表。
2. 夏日 DLC 正式 Rust 分析及转换成功，全部 5,874 个成员的路径、大小、CRC/摘要与真实包一致，必要条件正确表达；无游戏专属分支。
3. 本体/DLC、安装类型和包选择依实际配置求值，含子路径的只读条件能正确处理；向导/快捷方式等未应用操作不会造成误拒。
4. 各平台对其无法完成的真实提取操作给出具体原因；CRC 错误、截断或结构错位与合法配置差异分开处理。
5. Windows/SteamOS 对同一输入产出一致的载荷、选择和身份；真实安装、生效、取消恢复按后续授权范围验收。2026-10-14 计划阶段未执行；2026-10-15 正式 worker 回归已开始，实际游戏写入仍待验收。

此计划替代前一版“先审查尾标志，再扩大允许取值”的修复路线。诊断事实与历史验收记录不变，计划修订不表示代码已支持这些变化。

## 7. 实施补充

完整删除/保留依据见 [限制处理清单](policy-inventory.md)。包的 Install 默认值、安装前脚本修改以及成员 condition 决定选中载荷，多个包归属按 OR 处理；Enabled 是包选择界面的启用状态，不作为安装开关。install_type、extra 和 include 的构建期选择信息读出保留，不凭名称猜测为运行时组件。

报告 decoder/policy 升至 v2，明确携带 file_conditions；主进程依据当前游戏只读事实或同内容重装的可信原始事实筛选成员，worker 只转换已绑定的同一子集。UI 与卸载事件保留生命周期，避免完成/卸载屏幕影响安装选择。

验证边界：显示进度屏幕的两个配置 DWORD 尚未映射；While OnPreload 作为静态准备步骤处理。隐藏该屏幕且其 OnPreload 有选择副作用时，尚未与官方运行时核对。此项记录为行为覆盖边界，不新增配置值许可表。
