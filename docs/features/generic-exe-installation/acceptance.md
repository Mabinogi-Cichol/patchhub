## 完成审计与证据边界

1. 通用准入：三个 registry 外官方 SF9.5/9.6/9.7 包共用规则，空注册表实际安装；没有新增游戏/build/包摘要许可项。生产 `exe_generic` 仍将来源身份与内容/实例绑定，身份核对不作为游戏支持名单。
2. 行为覆盖：完整图/事件/include 经受限 AST 编译；任意文件名/CRC 参数允许，未知动作、动态调用、跨事件标志变更、进度分支副作用被拒绝。自动化结果沿用已执行的 35 项 SF 测试。
3. 条件：事实/来源/语言/DLC 与现场构建变更测试通过；当前 reviews 对新候选返回自动检查而非逐游戏审核，未知行为仍具体阻断。
4. 内容/权限：重新分析、重启路由不授权、租约/撤销、来源变化、载荷摘要与完整配方均有生产路径和自动化证据；69 项后端 EXE 运行中 67 通过、2 平台跳过，Linux 隔离由本机 WSL 和实际 Deck 补证。
5. 文件事务：39 项核心测试及四款实际故障/重装矩阵、真实 RPC 写入取消共同证明恢复和存档保护；设备只读 worker 不替代游戏事务证据。
6. UI/收据：旧 VBF 显示/收据可读；44 项 Decky 测试及类型检查、真实页面与合成任务交互、用户手柄确认分层记录。首次合成夹具错误匹配 SDK 参数，未知合成 task ID 请求未改变真实任务；修正后重新完整验收，恢复原 API，两个真实任务与基线一致。
7. 四款本地与最终 Deck：四款实际载荷/事务与用户游戏内生效确认齐全；最终部署/正式文件/HTTP bundle/实际组件/RPC/画面/手柄/只读大包 worker 和清理均完成。仍只支持已解释的安装器行为，不承诺所有 EXE。

当前没有本功能范围内的待实施或待验收项。设备任务截图中标记“合成 UI 验收任务（没有实际安装）”，下载速度/剩余时间为夹具数据，不能引用为真实性能。实际性能仅引用 `worker-result.json` 的隔离分析与转换耗时。
