# PatchHub 品牌与全面改名计划

[施工记录](progress.md) · [品牌素材](../../images/branding/README.md)

## 目标与授权范围

统一产品品牌为 **PatchHub**。用户确认项目仍处于内测阶段，可以接受破坏性变更，要求同时修改显示名称、GitHub 仓库、内部包名、可执行文件、数据目录和发行附件。本计划取代旧命名方案中“保留内部名称与目录”的未来实施策略；旧施工记录保留历史事实。

2026-10-25 用户要求“开始执行计划”，授权推进本地全面改名、构建验证及 GitHub 仓库改名。部署与正式版本发布仍按实施拆分中的授权边界处理，不能把本地候选包当作已发布版本。

## 视觉定稿

- 保留原有圆角拼图、左侧缺口及对勾结构，不采用几何 P、两块拼合或开放轨道备选方案。
- 拼图主体深炭黑；对勾和左侧缺口弧形边带均使用紫到蓝渐变。缺口内部与 Logo 外部透明。
- 配色方向：深炭黑 `#171A21`、紫 `#8B5CF6`、蓝 `#1A9FFF`；生成素材像素以实际文件为准。
- 首页横幅采用浅冷灰背景，确保深色 Logo 可辨识，右侧排列 PatchHub、Steam 游戏补丁助手、查找 · 下载 · 安装、Windows · Steam Deck。
- Logo PNG 1254 × 1254；横幅 2172 × 724（3:1）。Windows PNG 与品牌原图一致，ICO 从同一透明 PNG 导出。
- Decky 目前使用通用拼图组件；品牌菜单图标接入留在改名实施阶段，需检查游戏模式深色背景可读性。

## 破坏性变更边界

- 新版采用新身份和新目录，不新增旧名称别名、双路径发现或数据迁移框架；删除仅为旧品牌服务的兼容分支、配置、提示和专属测试。
- 旧用户按“卸载旧版、安装 PatchHub”处理，设置可能需要重新配置。旧自更新器不保证能够跨越此次身份变更，需要在切换说明中明确手动安装入口。
- 不自动删除旧数据、缓存或旧安装目录；用户接受兼容性中断不等于授权清除用户文件。
- 历史 Release、Tag、历史文档和验收证据不改写，不将旧版本附件重新命名。
- 更新当前源码、有效文档、技能中的操作示例、构建与远端入口；外部来源站名称、第三方包名和协议业务字段不因关键词相似而替换。
- 不改变查找、下载、安装业务范围，不增加主题系统、通用迁移层、任意硬限制或重试机制。

## 实施拆分与依赖

1. **素材与计划（本轮）**：替换品牌 PNG、Windows PNG/ICO，维护品牌说明及功能索引，记录实际验证。
2. **内部名称与本地链路**：盘点 Cargo/npm/Flutter 包、锁文件、导入、二进制、日志与数据路径、安装注册项、快捷方式、Decky 元数据及路由。按真实依赖顺序修改，完成两端本地构建后再处理外部入口。
3. **安装、打包与自更新**：与现有 client-self-update 工作整合；同步安装器、发布脚本、CI、附件匹配、自更新清单生成和消费方、校验和及 SBOM，移除旧品牌专属兼容逻辑。清单生成器与读取方必须使用同一命名契约。
4. **远端入口切换**：执行前核对目标仓库名可用性及权限；GitHub 仓库改为 patchhub，同步 origin、有效文档与源码下载 URL、工作流仓库引用。核查在线安装短链接的管理入口，确认实际落点指向新脚本；无法更新时明确记录阻塞项，不依赖重定向冒充完成。
5. **验证与交付**：完成下述矩阵，更新施工记录；文档与功能代码拆分提交，不夹带当前自更新功能的独立修改。发布与设备操作按届时授权执行。

当前分支由 main 创建。切换时保留了原 feature/client-self-update 的未提交工作区内容；这些内容不属于素材替换轮次。全面改名开始时工作区已干净，自更新及 Windows 修复已经提交并合入当前分支，以 `75cc867` 为本轮实现基线。后续仍需按功能与文档分开提交。

在线安装文档直接使用新仓库的完整 raw 脚本地址，不再推荐无法管理落点的旧短链接。新命名代码进入 main 且发布包含新名称附件的版本后，才能验收公开在线安装；保留历史 Release 不等于旧包可由新身份安装器消费。

| 本地构建 | clean npm 安装、Decky 类型检查/测试/构建，Cargo 检查及受影响测试，Flutter analyze/受影响测试与 Release 构建通过 |

## 过度设计审阅

依 overengineering-review 对本计划静态审阅：采用一次性内测身份切换，无需新旧兼容层；只清理旧品牌专属逻辑，保留业务及安全边界。不引入通用品牌配置框架。后续实现需沿实际安装、自更新及数据读写路径复核，当前结论不代表代码改名或实机验收完成。
