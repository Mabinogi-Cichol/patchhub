# Steam Deck 远程部署与验证

适用于本仓库 `apps/decky`。项目根目录由本技能目录向上三级定位，不假定当前工作目录。[AGENTS.md](../../../AGENTS.md) 中的插件开发规范仅适用于实际插件开发；单独创建/维护本技能不需要 feature 文档。涉及实际插件开发时，将实施或验证结果写入对应功能施工记录；单独部署/取证任务直接归档结果，详细 JSON、日志、截图与备份放忽略目录 `.artifacts/`。

## 工作范围

- 沿用用户已经授权的设备、部署范围与验证顺序；用户已要求部署时直接完成必要步骤。创建 skill、调研或只读检查不表示要求部署。
- 插件更新不包含游戏补丁安装/卸载、删除事务数据库、改变 DLC/Proton、修改 SteamOS 系统分区或其他插件。
- 不把设备 IP、密钥、端口、Loader 版本、文件数量或旧 SHA 固定成事实；每轮确认实际值。私钥只引用路径，不读取内容；token 不写入输出或提交文件。
- 部署前读取 `list_tasks`，确认没有非终态任务。任务状态未知或有下载/安装/回滚时，停止替换及重载，保留现场。

## 执行顺序

1. **连接与基线。** 读取 [连接和部署](references/deployment.md)。优先核对正在运行的 Devkit 所选设备和实际配对密钥路径，再使用该配对连接。旧 known_hosts 冲突时先检查本轮设备/网络及 Devkit 连接方式，不能直接判定设备不可达或要求用户手动取指纹。按参考中的当前配对核实与独立指纹记录流程继续；已有设备确认沿用，不重复询问。核实设备、插件身份、目录权限、服务、CEF 和状态目录。记录本次功能/提交、设备时间、变更文件、现有验证及活动任务。
2. **构建与清单。** 根据前端、Python、Rust 或完整包范围执行必要检查；用户已确认通过且没有新改动的验证沿用记录。构建完成后冻结待部署文件清单、大小及 SHA-256，不能用旧的 `dist` 或 Windows CLI 替代新产物。
3. **备份与暂存。** 保留本轮第一次有效旧文件备份和回滚材料；完整更新备份全部旧插件文件。保存 Loader 中本插件的设置与外部状态基线。上传到唯一暂存目录，逐文件核对后才能安装。
4. **部署。** 可写目录走明确文件清单的增量更新；root 所有或涉及完整替换时优先采用实际 Loader 支持的本地 ZIP + SHA-256 安装。不要 `chown`/`chmod -R`，不要盲试 sudo 或清空插件目录。失败时停止继续写入，依据回滚分支恢复。
5. **重载与运行时。** 读取 [运行时和界面验证](references/runtime-validation.md)。通过 Steam `SharedJSContext` 已有 Decky 连接操作。Python/CLI 变动需要后端重载；仅 `importPlugin` 不能证明后端已经更新。核对正式目录、实际 HTTP bundle、插件实例数、服务及新行为。
6. **RPC 与屏幕。** 调用实际 `scan(false)`、`list_tasks` 及本功能必要 RPC；检查真实 QAM 侧栏和全屏页，保存截图及滚动/布局结果。合成渲染和 DevTools 点击只证明对应行为，实体手柄焦点/返回另列验收项。
7. **归档与清理。** 取回备份、回滚包、证据到本地，逐项校验。确认运行正常后只清理本轮远端暂存内容；本地保留首次备份与证据。清理前验证绝对路径严格位于本轮验证目录且不指向插件、state、游戏或其父目录。
8. **报告。** 分别标明构建、已部署文件、运行时/RPC、真实屏幕、实体手柄的通过/失败/待验证；给出备份、哈希及证据路径。涉及实际插件开发时同步对应功能施工记录。不把以前的游戏数量、SHA 或截图当作本轮结果。

## 完成与停止条件

部署完成要求：正式文件与清单一致，CLI（如更新）为 Linux 可执行文件，`plugin_loader` 为 active，运行中插件实例为 1，实际加载新版前端/后端且必要 RPC 正常。界面任务还需检查真实画面，不能以文件哈希代替 UI 验收。

核对当前 Devkit 配对后仍无法确认 SSH 身份、目录/包身份不符、哈希不符、活动任务未结束、Loader API 无法确认、重载/RPC 异常或状态出现非预期变化时停止继续部署，归档错误并采取本轮已授权范围内的回滚。网络失败不无限重试；一次复核仍失败就报告连接问题，继续可完成的本地工作。自动审批拒绝时保留原因，不换通道绕过。

## 辅助工具

[scripts/cef.mjs](scripts/cef.mjs) 使用 Node 22+ 自带 fetch/WebSocket，通过 SSH 本地隧道列出 Steam CEF target、执行显式指定的 JS 文件、保存截图与 CDP JSON。默认只列出 target；不自动安装、重载或点击。使用方法见运行时参考；执行表达式前检查其副作用是否在当前用户授权内。
